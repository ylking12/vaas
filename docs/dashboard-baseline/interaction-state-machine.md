# 原大屏交互状态机

> 基于 v2 深度探测自动生成

## 默认状态
- 顶栏：标题"恶劣天气道路路面状态感知与预测系统" + 返回按钮 + S 图标
- 左侧：折叠态浮层（实时车队 / 路网状态 / 实时气象）
- 中心：高德地图（无锡，zoom 12）
- 底部：时间轴（过去 23h ─── 未来 1h）

## 状态机

```
[默认]
  │ 鼠标悬停"实时车队数据"
  ↓
[车队数据展开]
  │ 点击"实时数据"按钮
  ↓
[内容面板弹出（覆盖地图下半部分）]
  │   ├─ 选择气象站（下拉）
  │   ├─ 切换 radio（干湿/附着/温度）
  │   ├─ 拖动时间轴
  │   └─ 点击"导出"
  │ 点击关闭按钮
  ↓
[回到内容面板弹出]
  │ 点击关闭
  ↓
[默认]

[默认]
  │ 点击地图车辆标记
  ↓
[车辆信息弹窗]
  │   ├─ 查看车牌/速度
  │   └─ 关闭
  ↓
[默认]

[默认]
  │ 点击地图气象站标记
  ↓
[气象站信息弹窗]
```
