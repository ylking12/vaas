### 2.2 交互流程

| 操作 | 结果 |
|------|------|
| **鼠标悬停左边缘** | 左侧面板展开至 288px（默认折叠为 43px） |
| **点击"S"区域** | 触发面板切换（折叠/展开） |
| **点击"实时数据"按钮** | 弹出**全屏内容面板**，分三栏展示所有功能 |
| **点击"×"关闭按钮** | 关闭内容面板，回到地图全屏状态 |
| **拖动时间轴滑块** | 联动刷新事件数据和告警列表 |
| **点击地图上的车辆标记** | 弹出车辆信息浮窗（车牌号、速度） |
| **点击地图上的事件标记** | 弹出事件删除确认弹窗 |
| **点击气象站标记** | 弹出气象站数据浮窗 |
| **切换图层选项** | 地图叠加对应路况图层 |
| **点击"导出"** | 导出告警列表数据 |

## 3. 功能模块详情

### 3.1 顶部栏
- 系统标题："恶劣天气道路路面状态感知与预测系统"（居中）
- "返回"按钮（右上角）
- "S"图标（左上角，可切换面板折叠/展开）

### 3.2 左侧图层面板
**折叠态**（默认）：仅 43px 宽窄条，显示"S"图标 + "实时数据"按钮
**展开态**（悬停/点击展开）：288px 宽，包含：

**① 实时车队数据**
- 显示 "联网车辆"（当前在线车辆数）
- 切换：全部 / 出租车 / 巴士

**② 路网状态**（4个选项）
- 路面干湿状态图层
- 路面附着系数图层
- 路面温度状态图层
- 路面积水颠簸事件

**③ 实时气象数据**
- 降水量显示
- "查看气象设备"按钮

### 3.3 全屏内容面板（点击"实时数据"弹出）
关闭按钮（×）在左上角。面板分三栏：

**左栏：图层面板**（同上）

**中栏：路面状态 + 告警**
- **历史24小时路面状态**（ECharts 折线图）
- **道路实时路况**
  - 传感器切换下拉（5个气象站）
    - 文惠路与锦绣路
    - 先锋中路与新锡路
    - 机场路-泰山路
    - 高浪路-兴梁道
    - 运河西路
  - 数据卡片：空气温度（℃）、路面温度（℃）、相对湿度（%）
- **告警视图列表**
  - 表格列：路名 / 告警源 / 告警类型 / 时间
  - [导出]按钮
  - 按时间倒序

**右栏：服务统计**
- 覆盖面积（km²）
- 当前天气（阴/晴/雨等文字 + 图标）
- 最近24h内颠簸路面个数
- 最近24h内湿滑路面个数
- 最近24h内积水路面个数

### 3.4 时间轴（底部浮层）
- 范围：过去23h ~ 未来1h
- 刻度：15:00, 16:00, ..., Now, ..., 15:00
- 拖动时联动刷新

### 3.5 地图标记
- 车辆位置标记（实时）
- 事件标记（颠簸/湿滑/积水/结冰/低附着系数）
- 气象站标记（5个站点）
- 图层叠加（根据路网状态切换）

## 4. API 接口

| 方法 | 路径 | 参数 | 说明 |
|------|------|------|------|
| POST | `/get-alarm-list` | `{hour}` | 告警列表 |
| POST | `/get_real_time_sensor_data` | `{road_name}` | 传感器实时数据 |
| POST | `/get_last24h_data_plot` | `{road_name, data_title}` | 24h 图表数据 |
| POST | `/get_covered_range` | 无 | 覆盖范围 |
| GET | `/get_weather` | 无 | 天气数据 |
| POST | `/get-event-summary` | 无 | 事件统计汇总 |
| SSE | `/stream_data` | 实时推送 | bump/slip/ponding/ice/low_attachment |
| POST | `/delete-event` | `{eventId, eventType}` | 删除事件 |
| POST | `/get-last-24h-bump/slip/ice/ponding/low-attachment` | 无 | 各类24h事件 |

## 8. 交互确认（线上系统实测）

| 功能 | 交互方式 |
|------|---------|
| **路网状态3个图层** | 单选，点击立即切换。**积水颠簸事件**可与之共存（多选） |
| **联网车辆** | 动态显示在线车辆数 |
| **降水量** | 动态数据 |
| **查看气象设备** | 点击后地图定位到对应坐标（源码中存在坐标数据） |
| **导出** | Excel 格式 |
| **服务统计面板** | 跟随左侧面板一起出现和关闭，不是独立面板 |
| **时间轴 Now** | 当前时间标记为 Now |
| **路网图层面板** | 无 checkbox/radio，使用 `active` CSS 类切换样式 |
