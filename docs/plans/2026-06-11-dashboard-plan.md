## 任务清单

### Phase 1: 项目骨架 (4 tasks, ~1h)

| # | 任务 | 描述 | 验收标准 |
|---|------|------|---------|
| 1.1 | 创建 Vue 3 + Vite 项目 | 在 `frontend/dashboard/` 下初始化 Vue 3 项目，安装 Element Plus、ECharts、Axios、Vue Router、Pinia | `npm run dev` 正常启动 |
| 1.2 | 配置路由 + 环境变量 | 配置 `/dashboard` 路由，配置 `.env` 含 VUE_APP_URL、高德地图 Key/Secret | 路由跳转正常，环境变量可读取 |
| 1.3 | 配置 Axios + API 封装 | 封装所有 API 调用方法到 `src/api/` 目录 | API 调用返回正确数据 |
| 1.4 | 配置 Pinia 状态管理 | 创建 useDashboardStore：selectBur(时间选择)、sensorData(传感器数据) | 状态可读写 |

### Phase 2: 主布局 + 地图 (6 tasks, ~2h)

| # | 任务 | 描述 | 验收标准 |
|---|------|------|---------|
| 2.1 | 主布局组件 DashboardPage | 顶栏 + 左侧浮层 + 地图区 + 底部时间轴 + 内容面板 | 布局结构正确 |

| 2.3 | 高德地图加载 | 动态加载 AMap JS API v2.0，初始化地图（无锡 120.45/31.59，zoom=12） | 地图渲染成功 |
| 2.4 | 车辆位置标记 | 从 SSE 实时数据中提取车辆位置，在地图上标记 | 标记显示在地图上 |
| 2.5 | 事件标记 + 气象站标记 | 显示颠簸/湿滑/积水/结冰/低附着事件标记 + 5个气象站标记 | 标记可点击 |
| 2.6 | 标记弹窗 | VehiclePopup（车牌+速度）、RoadsidePopup（传感器数据）、EventPopup（删除确认） | 点击标记弹出正确信息 |

## 执行模式

项目较大，建议采用 **Subagent-driven** 模式：每个任务由一个子 Agent 负责实现，TDD 方式，完成后经 Code Review 合并。
